# ดีไซน์หน้าแอป

ม็อกอัปแบบโต้ตอบได้: https://claude.ai/artifact/PDdLrMEU8jy1oPQR1oW4hs (ตอนนี้เปิดได้เฉพาะเจ้าของ ถ้าจะให้คนอื่นดูต้องแชร์จากเมนู Share)

แนวทางดีไซน์: เน้นใช้งาน พื้นสีเทาอ่อน การ์ดสีขาว ใช้สีน้ำเงินเป็นสีหลัก และใช้สีส้มเป็นสีเตือน
(สีสถานะต่างกันทั้งความสว่างและเฉดสี จึงแยกออกได้แม้ผู้ใช้ตาบอดสี) ฟอนต์ Inter + IBM Plex Sans Thai
ส่วนชื่อตัวแปรและ JSON ใช้ JetBrains Mono ปุ่มทุกปุ่มสูงอย่างน้อย 44px และแต่ละหน้าใช้งานบนมือถือได้ (เมนูจะย้ายลงไปซ้อนด้านล่าง)

## Flow

```
หน้าหลัก ──อัปโหลด──► ดูผลเอกสาร ──"ใช้เป็นตัวอย่าง"──► สอน Template ──บันทึก──► คลัง Template
   ▲                      │  (แก้ค่า → สอนเพิ่ม)              ▲                        │
   └──────────────────────┴───────────────────────────────────┴──── ทดสอบการจับคู่ ◄──┘
```

## หน้าจอ

| # | หน้า | ใช้ทำอะไร | ส่วนประกอบหลัก | ฟังก์ชันใน backend |
|---|------|-----------|----------------|--------------------|
| 1 | **หน้าหลัก / อัปโหลด** | ส่งไฟล์เข้า ดูภาพรวม | ช่องลากวางไฟล์, ตัวเลือก "จำ Template อัตโนมัติ" และ "โหมดปลอดภัย", การ์ดสรุป, ตารางเอกสารล่าสุด (สถานะ: สำเร็จ / ขาดตัวแปรบังคับ / ต้อง OCR / อ่านไม่ได้) | `extract_isolated`, `TemplateStore.best`, `extraction.status`, `missing_required_fields`, `needs_ocr` |
| 2 | **ดูผลเอกสาร** | ตรวจและแก้ผล | ภาพหน้า PDF พร้อมกรอบไฮไลต์ (ตัวแปร = น้ำเงิน, ตาราง = ส้ม, บล็อก = เส้นประ), แท็บ **ตัวแปร** (ค่า, ข้อความต้นฉบับ, หน้า, วิธีที่หาเจอ, แก้ค่าได้), **โครงสร้าง** (blocks/tables/warnings), **JSON** | `fields[*].raw/page/method`, `bbox`, `pages[*].blocks/tables` |
| 3 | **สอน Template** | ให้ระบบเรียนรู้ | แถบความคืบหน้า 4 ขั้น (อ่านไฟล์ → หาป้าย:ค่า → เทียบตัวอย่าง → สร้าง+ทดสอบ), รายการไฟล์ตัวอย่าง, ตารางตัวแปรที่เรียนรู้ได้ (ชื่อ, ป้าย, ชนิด, เจอใน x/n, บังคับ, รูปแบบ), การจับคู่คอลัมน์ตาราง, anchors, คำเตือนเมื่อค่าเหมือนกันทุกใบ | `observe`, `build_template`, `TemplateStore.learn`, `field_stats`, `anchors` |
| 4 | **คลัง Template** | จัดการและทดสอบ | การ์ด Template (จำนวนตัวอย่าง/ตัวแปร/anchors, อัตราที่หาเจอ, ป้าย "เรียนรู้อัตโนมัติ" หรือ "แก้ spec เอง"), ปุ่มเพิ่มตัวอย่าง/แก้ spec/ส่งออก YAML, ส่วนทดสอบการจับคู่ที่แสดงคะแนนเทียบเกณฑ์ | `TemplateStore.list/match/set_spec`, `spec_yaml` |

## สิ่งที่ต้องทำต่อเพื่อให้เป็นแอปจริง (Phase 5)

1. REST API (FastAPI) ที่ครอบฟังก์ชันในตารางด้านบน และใช้ job queue + progress event สำหรับแถบความคืบหน้าในหน้า 3
2. Endpoint สำหรับ render ภาพหน้า PDF (pypdfium2) เพื่อใช้วาดกรอบ `bbox` ในหน้า 2
3. บันทึกค่าที่ผู้ใช้แก้ในหน้า 2 เป็น feedback เพื่อปรับ label/pattern ของ Template (ดู roadmap Phase 4)
4. Frontend (React/Vue) ตามดีไซน์นี้

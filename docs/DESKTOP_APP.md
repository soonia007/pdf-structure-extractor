# แอปบนเครื่อง (Desktop App)

แอปนี้ใช้ทุกอย่างของ pdfstruct ผ่านหน้าต่างแอป: อัปโหลด PDF, ดูผลบนหน้าเอกสาร, สอน Template และจัดการคลัง Template
หน้าตาเป็นไปตาม [APP_DESIGN.md](APP_DESIGN.md) **ทำงานในเครื่องทั้งหมด ไม่ส่งไฟล์ออกอินเทอร์เน็ต**

## วิธีที่ 1: ดาวน์โหลดแอปสำเร็จรูป (ไม่ต้องติดตั้ง Python)

1. ไปที่แท็บ **Actions** ของ repo → เลือก **Build desktop app** → กด **Run workflow**
   (หรือ push tag เช่น `v0.2.0` ไฟล์จะไปอยู่ในหน้า **Releases** ด้วย)
2. รอให้ build เสร็จ (ประมาณ 5–10 นาที) แล้วดาวน์โหลดจากส่วน **Artifacts** ด้านล่างของหน้า run
   - Windows: `pdfstruct-windows.zip` → แตกไฟล์ → เปิด `pdfstruct\pdfstruct.exe`
   - macOS: `pdfstruct-macos.zip` → แตกไฟล์ → เปิด `pdfstruct.app`
     (ครั้งแรกให้คลิกขวา → Open เพราะแอปยังไม่ได้ sign กับ Apple)
   - Linux: `pdfstruct-linux.tar.gz` → แตกไฟล์ → รัน `pdfstruct/pdfstruct`
     (ถ้าเครื่องไม่มี GTK/Qt แอปจะเปิดในเบราว์เซอร์แทน)

> Windows SmartScreen อาจเตือนว่า "unrecognized app" เพราะยังไม่ได้ซื้อ code-signing certificate ให้กด More info → Run anyway

## วิธีที่ 2: รันจากซอร์สโค้ด (สำหรับนักพัฒนา)

```bash
pip install -e ".[app]"      # pywebview สำหรับหน้าต่างแอป
pdfstruct-app                # เปิดเป็นหน้าต่าง
pdfstruct-app --browser      # หรือเปิดในเบราว์เซอร์
```

ตัวเลือก:
- `--store DIR` ใช้กำหนดโฟลเดอร์ Template (ค่าเริ่มต้น `~/.pdfstruct/templates` หรือตามตัวแปร `PDFSTRUCT_TEMPLATES`)
- `--no-isolate` อ่าน PDF ใน process เดียวกับแอป ทำงานเร็วขึ้นแต่ความเสถียรลดลง
- `--port N` ใช้กำหนดพอร์ต

ถ้าจะ build แอปเอง:

```bash
pip install -e ".[build]"
python packaging/build.py    # ได้ dist/pdfstruct/ (หรือ dist/pdfstruct.app บน macOS)
```

PyInstaller build ข้ามระบบปฏิบัติการไม่ได้ ถ้าต้องการไฟล์สำหรับ Windows ต้อง build บน Windows (workflow ใน Actions จัดการให้ครบทั้ง 3 ระบบ)

## ใช้งาน

| ขั้น | ทำอะไร |
|------|--------|
| 1. **หน้าหลัก** | ลากไฟล์ PDF มาวาง (หลายไฟล์พร้อมกันได้) ถ้าเปิด "จำ Template อัตโนมัติ" ระบบจะจับคู่กับ Template ที่มีอยู่แล้วดึงค่าให้ทันที |
| 2. **ดูผลเอกสาร** | ดูหน้า PDF ที่มีกรอบสีน้ำเงิน (ตัวแปร) และสีส้ม (ตาราง) ในแท็บ **ตัวแปร** แก้ค่าได้แล้วกด "บันทึกการแก้ไข" ส่วนแท็บ **โครงสร้าง** และ **JSON** แสดงข้อมูลทั้งหมด กด **ส่งออก JSON** เพื่อบันทึกไฟล์ |
| 3. **สอน Template** | ตั้งชื่อ (อังกฤษ/ตัวเลข/`_`) เลือกไฟล์ตัวอย่างที่เป็นเอกสารแบบเดียวกัน 2–3 ไฟล์ แล้วกด **เริ่มเรียนรู้** แถบความคืบหน้าจะแสดงแต่ละขั้น จากนั้นตรวจตารางตัวแปรที่ได้ และกด **แก้ spec (YAML)** ถ้าต้องการปรับ |
| 4. **คลัง Template** | ดู แก้ ส่งออก หรือลบ Template ได้ และใช้ **ทดสอบการจับคู่** กับเอกสารที่อัปโหลดแล้ว |

เอกสารที่อัปโหลดจะถูกลบเมื่อปิดแอป แต่ Template จะเก็บถาวรในโฟลเดอร์ store

## ไฟล์ที่ล็อกด้วยรหัสผ่าน

เมื่ออัปโหลด PDF ที่ต้องใช้รหัสผ่านเปิด หน้าต่าง **ใส่รหัสผ่าน** จะเด้งขึ้นมาเอง
(หรือกดปุ่ม **ใส่รหัสผ่าน** ในรายการเอกสาร ซึ่งไฟล์จะมีสถานะ "ล็อกด้วยรหัสผ่าน")

- อัปโหลดหลายไฟล์ที่ใช้รหัสเดียวกัน ติ๊ก **"ลองรหัสนี้กับทุกไฟล์ที่ล็อก"** เพื่อปลดล็อกทีเดียว
- ถ้ารหัสผิด จะขึ้นว่า "รหัสผ่านไม่ถูกต้อง" แล้วลองใหม่ได้ หรือกด **ข้ามไปก่อน** แล้วกลับมาใส่ภายหลัง
- ปลดล็อกแล้วใช้ได้ทุกอย่างเหมือนไฟล์ปกติ ทั้งดูหน้าเอกสาร ซูม จับคู่ Template ครอปตัวแปร สอน Template และส่งออก
- **ความปลอดภัย:** รหัสผ่านถูกเก็บไว้ในหน่วยความจำของแอปจนปิดแอปเท่านั้น ไม่บันทึกลงเครื่อง ไม่อยู่ในไฟล์ JSON
  ที่ส่งออก และแอปไม่สร้างไฟล์ฉบับถอดรหัสเก็บไว้
- PDF ที่ล็อกแค่สิทธิ์การแก้ไขหรือพิมพ์ (owner password) เปิดอ่านได้เลยโดยไม่ต้องใส่รหัส

ผ่าน command line ใช้ `--password` ได้ (ใช้กับ `--auto-template` และตัวแปรครอปได้ด้วย):

```bash
pdfstruct locked.pdf --password 1234 --auto-template --fields-only --pretty
```

## ซูมเอกสาร

ปุ่ม `−` / `+` (50–400%), ปุ่ม **พอดีความกว้าง** และกดที่ตัวเลข % เพื่อกลับเป็น 100%
- **Ctrl + ล้อเมาส์** (Mac: ⌘ + ล้อเมาส์) ซูมโดยตำแหน่งใต้เมาส์ไม่เลื่อนไปไหน ส่วนล้อเมาส์อย่างเดียวใช้เลื่อนหน้าเหมือนเดิม
- คลิกที่หน้าเอกสารแล้วกด `+` `-` `0` บนคีย์บอร์ดได้
- ซูมเข้าแล้วภาพจะคมขึ้น ครอปตัวแปรได้ที่ทุกระดับซูม (ซูมเข้าช่วยครอปค่าตัวเล็ก ๆ ได้แม่นขึ้น)
- คลิกการ์ดตัวแปรทางขวา หน้าเอกสารจะเลื่อนไปที่กรอบของตัวแปรนั้น
- แอปจำระดับซูมล่าสุดไว้ให้

## ส่งออก และ Prompt สำหรับนำไปใช้กับ AI

กด **ส่งออก** ในหน้าดูผลเอกสาร (ค่าที่แก้ไว้จะถูกบันทึกก่อนส่งออก)

| ไฟล์ | ใช้ทำอะไร |
|------|-----------|
| **JSON เต็ม** | โครงสร้างทั้งหมด: ข้อความ บล็อก ตาราง ตำแหน่ง ตัวแปร สำหรับนักพัฒนา |
| **JSON เฉพาะตัวแปร** | `{"fields": {"total": 200, ...}}` สั้น อ่านง่าย เหมาะส่งต่อระบบอื่นหรือ AI |
| **CSV (Excel)** | ตัวแปร 1 แถวต่อค่า ตารางเป็น `items[1].qty` เปิดใน Excel แล้วภาษาไทยไม่เพี้ยน |

**Prompt สำเร็จรูป** (ใส่ข้อมูลของเอกสารนั้นไว้แล้ว กด **คัดลอก Prompt** แล้ววางใน Claude หรือ ChatGPT):

| Prompt | ได้อะไร |
|--------|---------|
| สรุปเอกสาร | ประเภทเอกสาร, ข้อมูลสำคัญ, สิ่งที่ขาด |
| ตรวจความถูกต้อง | ตารางผลตรวจ: ยอดรวมตรงกับรายการ, วันที่, เลขผู้เสียภาษี 13 หลัก → "พร้อมใช้" หรือ "ต้องแก้ไข" |
| แปลงเป็นตาราง Excel / CSV | CSV 1 แถวต่อรายการ วางใน Excel หรือ Google Sheets ได้ทันที |
| นำเข้าฐานข้อมูล (SQL) | `CREATE TABLE` + `INSERT` (PostgreSQL) พร้อมกันนำเข้าซ้ำด้วย sha256 |
| เขียนโค้ดอ่านไฟล์ JSON | โค้ด Python รวม JSON หลายไฟล์เป็น Excel ไฟล์เดียว |
| ถาม–ตอบจากเอกสาร | เริ่มแชตถามข้อมูล โดยให้ AI ตอบจากเอกสารเท่านั้นและบอกที่มา |
| แปลงเป็นรูปแบบระบบอื่น | แปลงเป็นรูปแบบระบบบัญชีหรือ ERP (วางตัวอย่างรูปแบบปลายทางในช่องที่เตรียมไว้) |

ถ้าเอกสารยังไม่มีตัวแปร Prompt จะใช้ข้อความและตารางจากหน้าเอกสารแทน (สูงสุด 12,000 ตัวอักษร)

**ความปลอดภัย:** ข้อมูลเอกสารใน Prompt ถูกครอบด้วย `<document_data>` และสั่งให้ AI ถือเป็นข้อมูลเท่านั้น
ถ้าใน PDF มีข้อความที่ดูเหมือนคำสั่ง AI จะไม่ทำตาม แต่ Prompt มี **ข้อมูลจริงจากเอกสาร**
ตรวจให้แน่ใจว่าส่งข้อมูลนี้ให้บริการ AI ภายนอกได้ตามนโยบายขององค์กร

ใช้ผ่าน command line ได้เช่นกัน:

```bash
pdfstruct invoice.pdf --auto-template --prompt validate > prompt.txt
```

## ครอปตัวแปรเอง (สอนด้วยตัวเอง)

ใช้เมื่ออยากกำหนดเองว่าตัวแปรอยู่ตรงไหน แทนการให้ระบบเดา

1. อัปโหลด PDF 1 ไฟล์ แล้วเปิดหน้า **ดูผลเอกสาร**
2. กด **ครอปตัวแปร** แล้วลากกรอบครอบค่าที่ต้องการบนหน้าเอกสาร
3. หน้าต่างจะแสดง **ค่าที่อ่านได้ในกรอบ** ทันที ให้ตั้งชื่อตัวแปร (เช่น `total`) เลือกชนิดข้อมูล
   - ถ้าในกรอบมีทั้งป้ายและค่า เช่น `Grand Total: 200.00 THB` ให้ใส่รูปแบบ (regex) เช่น `[\d,]+\.\d{2}` เพื่อดึงเฉพาะตัวเลข
   - ถ้าครอบทั้งตาราง ให้เลือกชนิด **ตาราง** จะได้ทุกแถวโดยใช้แถวแรกเป็นชื่อคอลัมน์
4. เลือก Template ที่จะบันทึก หรือสร้างใหม่ แล้วกด **บันทึกตัวแปร**
5. ทำซ้ำจนครบทุกตัวแปร ตัวแปรที่ครอปจะแสดงเป็นกรอบ **สีม่วง**

เอกสารแบบเดียวกันที่อัปโหลดภายหลังจะถูกจำได้และอ่านค่าจากกรอบเหล่านี้ให้อัตโนมัติ

- **กรอบขยับตามป้าย:** ตอนบันทึก ระบบจะจำข้อความคงที่ที่อยู่ใกล้กรอบ (เช่นป้าย "Grand Total")
  ถ้าเอกสารใบอื่นมีรายการมากกว่าจนป้ายเลื่อนลง กรอบจะเลื่อนตามไปด้วย ในช่องตัวแปรจะแสดงว่า "ครอป (ขยับตามป้าย)"
- Template ที่เริ่มจากการครอปจะมี **เฉพาะตัวแปรที่คุณครอป** (ป้าย "ครอปเอง" ในคลัง Template)
  ระบบยังจำข้อความคงที่ไว้ใช้จับคู่เอกสาร
- ลบตัวแปรได้ด้วยปุ่ม **ลบ** บนการ์ดตัวแปร ถ้าเป็นตัวแปรที่ระบบเรียนรู้เอง การลบจะถูกจำไว้ แม้เรียนรู้ใหม่ก็จะไม่กลับมา
- **ข้อจำกัด:** ถ้าเอกสารแต่ละใบมีตำแหน่งต่างกันมาก หรือหาป้ายใกล้กรอบไม่เจอ ระบบจะใช้ตำแหน่งเดิมของกรอบ ควรตรวจผลกับเอกสาร 2–3 ใบ

## ความปลอดภัย

- เซิร์ฟเวอร์ภายในฟังเฉพาะ `127.0.0.1` ไม่เปิดให้เครื่องอื่นในเครือข่ายเข้าถึง
- ทุกคำขอต้องมีรหัสลับที่สุ่มใหม่ทุกครั้งที่เปิดแอป และตรวจ Host header เพื่อกันการโจมตีแบบ DNS rebinding
- เว็บไซต์อื่นที่เปิดอยู่ในเบราว์เซอร์จึงเรียก API ของแอปไม่ได้
- PDF ถูกอ่านใน process แยกที่มี timeout ถ้าไฟล์เสียหรือทำให้ parser ค้าง แอปจะไม่ล่ม
- ไฟล์ที่อัปโหลดเก็บในโฟลเดอร์ชั่วคราวส่วนตัว และถูกลบเมื่อปิดแอป

# OCR: อ่านเอกสารที่เป็นภาพสแกน

PDF ที่สแกนมาเป็นแค่ "รูปภาพ" ไม่มีตัวอักษรอยู่ข้างใน โปรแกรมจึงต้องใช้ **OCR** (การอ่านตัวอักษรจากภาพ)
pdfstruct ใช้ **Tesseract OCR** ซึ่งเป็นโปรแกรมฟรี อ่านได้ทั้งภาษาไทยและอังกฤษ

## ทำงานอัตโนมัติเมื่อไหร่

- หน้าที่ **ไม่มีชั้นข้อความ** (ภาพสแกนหรือภาพถ่าย)
- หน้าที่ข้อความ **เพี้ยนเกิน 30%** ซึ่งเจอบ่อยใน PDF ภาษาไทยที่ฟอนต์ไม่มีตาราง Unicode (อ่านออกมาเป็นตัวแปลก ๆ)

ผลจาก OCR ผ่านขั้นตอนเดียวกับ PDF ปกติ จึงหาตัวแปร เรียนรู้ Template และครอปได้เหมือนกัน
ในแอปจะมีป้าย **OCR xx%** ที่หัวเอกสาร และความมั่นใจของตัวแปรจากหน้า OCR จะลดลงตามความมั่นใจของ OCR
ตัวแปรที่ความมั่นใจต่ำกว่า 75% จะมีป้าย **"ควรตรวจ"**

```bash
pdfstruct scan.pdf --ocr auto     # ค่าเริ่มต้น: OCR เฉพาะหน้าที่จำเป็น
pdfstruct scan.pdf --ocr force    # OCR ทุกหน้า (เช่น PDF ที่ข้อความในไฟล์ผิด)
pdfstruct scan.pdf --ocr off      # ไม่ใช้ OCR
```

## ติดตั้ง

| ระบบ | วิธี |
|------|------|
| **Windows (แอปที่ดาวน์โหลดจาก Actions)** | **ไม่ต้องติดตั้ง** มี Tesseract พร้อมภาษาไทยอยู่ในโฟลเดอร์ `pdfstruct\tesseract` แล้ว |
| Windows (รันจากโค้ด) | ติดตั้งจาก https://github.com/UB-Mannheim/tesseract/wiki แล้วติ๊ก **Thai** ใน Additional language data |
| macOS | `brew install tesseract tesseract-lang` |
| Ubuntu / Debian | `sudo apt install tesseract-ocr tesseract-ocr-tha` |

ถ้าติดตั้งไว้ที่อื่น ให้ตั้งค่า `PDFSTRUCT_TESSERACT=C:\path\to\tesseract.exe`
ตรวจสถานะได้ที่มุมล่างซ้ายของแอป (`OCR: พร้อม (ไทย+อังกฤษ)`) หรือรัน `pdfstruct-app --ocr-check status.json`

## ข้อจำกัดและคำแนะนำ

- **สแกนที่ 300 dpi** ขึ้นไป ภาพตรง ไม่เอียง จะได้ผลดีที่สุด ถ้าความละเอียดต่ำ สระและวรรณยุกต์ไทยอาจหายหรือเพี้ยน
- OCR อาจอ่านตัวอักษรผิด ควรตรวจค่าที่มีป้าย "ควรตรวจ" ก่อนใช้งานจริง
- ลายมือเขียนอ่านไม่ได้ (Tesseract อ่านได้เฉพาะตัวพิมพ์)
- OCR ใช้เวลาประมาณ 2–5 วินาทีต่อหน้า
